# idcard-agent (PowerShell) — อ่านบัตรประชาชนจากเครื่องอ่านสมาร์ทการ์ด

โปรแกรมอ่านชิปบัตรประชาชนไทยโดยตรงจากเครื่องอ่าน USB (PC/SC)
**ไม่ต้องติดตั้งอะไรเพิ่ม** — ใช้ PowerShell + .NET (winscard.dll) ที่มากับ Windows อยู่แล้ว
(ไม่ต้องลง Node.js, ไม่ต้อง compile, ไม่ต้องลง Build Tools)

> ต่างจากโฟลเดอร์ `card-agent/` (เวอร์ชัน Node.js ที่ต้อง compile) — เวอร์ชันนี้รันได้ทันทีบน Windows

---

## สิ่งที่ต้องมี
- Windows (มี PowerShell + .NET Framework มาให้อยู่แล้ว)
- เครื่องอ่านสมาร์ทการ์ด **มาตรฐาน PC/SC** (USB) — ตัวเดียวกับที่ SIAM-ID ใช้
- บริการ **Smart Card** ของ Windows เปิดอยู่ (ปกติเปิดอัตโนมัติ)

## วิธีใช้ (ทุกครั้งก่อนใช้งาน)
1. **ปิดโปรแกรม SIAM-ID ก่อน** (ไม่งั้นแย่งจับบัตรกัน)
2. ดับเบิลคลิก **`START-อ่านบัตร.bat`**
   - ถ้า Windows เตือน "SmartScreen" ให้กด *More info > Run anyway*
3. ขึ้นข้อความ `idcard-agent พร้อมใช้งานที่ http://localhost:8765` = พร้อม
   (เปิดหน้าต่างดำนี้ค้างไว้)
4. เสียบบัตรที่เครื่องอ่าน → ในเว็บแอปกดปุ่ม **"อ่านบัตร"**
5. ระบบดึง เลขบัตร / ชื่อ-สกุล / วันเกิด / เพศ / ที่อยู่ (แยกช่องให้) / **รูปจากบัตร** มากรอกอัตโนมัติ

## รันแบบพิมพ์คำสั่งเอง (ถ้า .bat มีปัญหา)
เปิด PowerShell ในโฟลเดอร์นี้ แล้ว:
```powershell
powershell -ExecutionPolicy Bypass -File idcard-agent.ps1
```

## แก้ปัญหาเบื้องต้น
| อาการ | วิธีแก้ |
|-------|---------|
| เว็บเด้งช่อง "แตะบัตร (SIAM-ID)" | ยังไม่ได้เปิด agent (`START-อ่านบัตร.bat`) หรือปิดหน้าต่างไป |
| "ยังไม่ได้เสียบบัตร" | เสียบบัตรให้แน่น รอ 1-2 วินาที แล้วกดอ่านใหม่ |
| "ไม่พบเครื่องอ่านบัตร" | เสียบเครื่องอ่าน USB / ตรวจว่าบริการ Smart Card เปิดอยู่ |
| อ่านไม่ได้ทั้งที่เสียบแล้ว | ปิด SIAM-ID (แย่งจับบัตร) แล้วลองใหม่ |
| SmartScreen บล็อก .bat | More info > Run anyway (ไฟล์นี้เป็นสคริปต์ในเครื่อง ไม่ออกเน็ต) |

## ความปลอดภัย
- เปิดพอร์ตเฉพาะในเครื่อง `127.0.0.1:8765` เท่านั้น — ไม่เปิดออกอินเทอร์เน็ต
- อ่านข้อมูลจากบัตรส่งให้เว็บในเครื่องเดียวกัน ไม่ได้ส่งข้อมูลไปที่อื่น
- ข้อความไทยในบัตรเข้ารหัส TIS-620 (code page 874) โปรแกรมแปลงเป็น UTF-8 ให้

> โค้ดอ้างอิงตามสเปกบัตรประชาชนไทยมาตรฐาน หากเครื่องอ่านบางรุ่นมีพฤติกรรมต่าง แจ้งรุ่นมาได้ ปรับให้ตรงรุ่นได้
